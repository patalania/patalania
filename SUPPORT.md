# Support

**Patalania is provided as-is. There is no support.** You may report bugs via GitHub Issues; there is no guarantee of a response or a fix.

> **This software is not provided or supported by Linden Lab, the makers of Second Life.**
> It is also not provided or supported by The Phoenix Firestorm Project, Inc. Please do **not** report Patalania problems to Linden Lab or to the Firestorm team.

## Bug reports

- Report bugs at <https://github.com/patalania/patalania/issues> (template "Bug report"). Reports in English or German are welcome.
- Please test with an official release and search existing issues before reporting.
- A useful report contains: Patalania version, Linux distribution, graphics card and driver, grid (Second Life / OpenSim), what you did, what you expected, what happened, and the end of `~/.patalania_x64/logs/Patalania.log` (remove anything private first). For VR problems also state the headset and OpenXR runtime (e.g. WiVRn) with version.
- Do not post passwords or private data.

## Other resources

- [docs/HELP.md](docs/HELP.md) – getting started; most features are inherited from Firestorm and described in its documentation.
- [docs/KNOWN_LIMITATIONS.md](docs/KNOWN_LIMITATIONS.md).
- **Grid or account problems** (login refused, inventory, billing, in-world rules): contact the operator of the grid you use. For Second Life that is Linden Lab's own support.

## Security issues

Please do not post vulnerabilities publicly. Use GitHub's "Report a vulnerability" function on the repository's Security tab.
