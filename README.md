# Patalania

**Patalania** is a work-in-progress third-party viewer for 3D virtual worlds such as Second Life and OpenSim grids. Its goal is a native OpenXR VR view on Linux (via WiVRn, e.g. Meta Quest 3) that is controlled with keyboard and mouse.

> **Status: in development.** There are no releases yet, and the viewer does not yet differ from its base.

## Base
